# Contributing

Lean-SDD is experimental. Contributions should strengthen the protocol through concrete use rather than add process for its own sake.

1. Open an issue describing the problem or learning.
2. Prefer a small change with a worked example.
3. Keep terminology aligned with Intent → Spec → Slice → Evidence → Learning.
4. Add tests for CLI behaviour.
5. Avoid adding mandatory fields unless they remove recurring, demonstrated ambiguity.
