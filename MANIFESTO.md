# Lean-SDD Manifesto

We believe in:

- Outcomes over outputs.
- Small specifications over comprehensive requirements.
- Vertical slices over large implementation plans.
- Evidence over assertions.
- Production learning over specification certainty.
- Flow over utilization.
- Evolution over conformance to an obsolete plan.
- Human intent over AI autonomy.

Therefore we:

- Specify only enough to remove meaningful uncertainty.
- Build the smallest behaviour worth learning from.
- Make important behaviour verifiable.
- Limit specification and implementation work in progress.
- Treat unimplemented specifications as inventory.
- Treat production evidence as part of development.
- Allow evidence to change the specification.
- Do not let AI implementation outrun human intent.
